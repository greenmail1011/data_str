01｜資料結構與演算法有什麼不同？

資料結構回答「資料怎麼存」，演算法回答「問題怎麼解」。兩者相互配合。

資料結構 Data Structures

組織與儲存資料的方式，例如 Stack、Queue、Tree、Graph、Heap。

演算法 Algorithms

處理資料、解決問題的步驟，例如 BFS、DFS、Dijkstra、排序、動態規劃（DP）。

02｜核心資料結構圖解

用簡單示意圖掌握資料如何存放與操作。

陣列／串列 Array / List

依照索引存取元素。應用：成績統計、搜尋、排序。

堆疊 Stack

後進先出（LIFO）。應用：括號配對、復原操作、DFS。

佇列 Queue

先進先出（FIFO）。應用：排隊系統、BFS、工作排程。

樹 Tree

父子節點形成階層。應用：階層分類、搜尋、優先佇列。

圖 Graph

頂點與邊構成網路。應用：地圖導航、社群網路、最短路徑。

鏈結串列 Linked List

節點透過參照互相連接。應用：動態串接與節點操作。
